# Security and sensitive information

Never open a public issue containing a vulnerability in a real organization, credentials, or personal data. Use the affected owner's approved private reporting channel. This repository is not an authorized disclosure channel for an employer.

If sensitive information is committed: stop sharing it, notify the data owner privately, revoke affected credentials through their owner, and agree on repository/history cleanup. Deleting a file does not remove Git history. Do not rewrite history without explicit authorization.

Contributions here must be synthetic or expressly approved for publication. No active testing of external systems is authorized by this document.
